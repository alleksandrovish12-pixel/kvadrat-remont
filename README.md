# КВАДРАТ — лендинг ремонта квартир и санузлов

Готовый одностраничный сайт с интерактивным калькулятором предварительной стоимости ремонта.

## Файлы

```
index.html        — разметка и весь контент
css/styles.css    — стили и адаптивность
js/main.js        — калькулятор, меню, форма, анимации
```

Откройте `index.html` в браузере — сборка и сервер не нужны.

## Что уже работает

- Калькулятор с двумя режимами: «Квартира целиком» и «Только санузел».
- Площадь, уровень ремонта, количество санузлов, размер санузла.
- Дополнительные работы: демонтаж, электрика, сантехника, выравнивание, потолки, тёплый пол, инсталляция, дизайн-проект.
- Мгновенный пересчёт работ, материалов, итоговой суммы, срока и цены за м².
- Кнопка «Получить точную смету» переносит расчёт в форму заявки.
- Маска телефона, валидация, экран успешной отправки.
- Мобильное меню, липкая панель звонка, FAQ-аккордеон, анимации появления.

## Как менять цены калькулятора

Базовые ставки — в `js/main.js` в объекте `LEVELS`:

```js
cosmetic: { apt: 9500, bathStd: 210000, ... }
capital:  { apt: 16500, bathStd: 290000, ... }
design:   { apt: 27000, bathStd: 390000, ... }
```

Дополнительные работы задаются в `index.html` атрибутами чекбоксов:

```html
data-price="2800" data-unit="m2"      <!-- цена за м² -->
data-price="18000" data-unit="bath"   <!-- цена за санузел -->
data-type="percent" data-price="0.12" <!-- +12% к работам -->
```

Доли материалов и диапазон стоимости — константы `MATERIAL_RATE`, `MATERIAL_MIN`, `MATERIAL_MAX` в `js/main.js`.

## Форма заявки

Сейчас форма работает в демо-режиме: проверяет поля и показывает сообщение об успехе, но никуда не отправляет данные. Для реальных заявок подключите обработчик в конце `contactForm.addEventListener('submit', ...)` в `js/main.js` — например, к CRM, Telegram-боту или почтовому API.

## Публикация

Подойдёт любой статический хостинг: GitHub Pages, Netlify, Vercel, Cloudflare Pages или обычный хостинг с загрузкой по FTP. Достаточно загрузить три папки/файла: `index.html`, `css/`, `js/`.

Шрифты Manrope и Inter подключены с Google Fonts; при отсутствии интернета используются системные шрифты.
